# R2 PDF input foundation

> Updated: 2026-09-24. Bounded PDF extraction and Worker-context selection are implemented locally; the R2 format profile is not release-qualified.

Direct `.pdf` uploads are stored as a deterministic `pdf_snapshot` gzip/tar package. The package contains the original PDF, a versioned extraction record, and extracted UTF-8 text when available. Its outer CAS digest binds all three; the internal directory manifest hashes each file. Revalidation rebuilds the package from the preserved PDF and requires byte-for-byte canonical equality.

The pinned parser is `github.com/giraffesyo/pdf@v0.7.0`. Intake limits the PDF source to 6 MiB, parses at most 40 pages sequentially, caps each decoded stream at 1 MiB, caps page operators/glyphs/forms/images, limits processing time, and stores at most 16 KiB of extracted text. Parser warning codes, page coverage, image-bearing pages, truncation, original SHA-256, extracted-text SHA-256, and parser version are stored in `pdf/extraction.json`. Parser errors are mapped to safe reason codes; uploaded document text is not echoed in errors.

Only extracted text and the extraction record can enter the Worker context. The original PDF is an explicit `representation_not_supported` exclusion, bound to the frozen input and file digest. A scanned PDF receives no invented text and no OCR; its upload remains partial with its original bytes and a `no_text` record. The frontend names the PDF limit and this extraction boundary.

Offline tests cover text extraction reaching `PrepareModelInputContext`, canonical package/hash verification, original-byte preservation, no-text handling, text truncation, malformed/oversized/mislabeled input rejection, and nested PDF preservation without parser recursion. A disposable PostgreSQL 18 cluster applied migrations 00001–00026. `TestProductWorkerReceivesExtractedTextFromBoundPDFInput`, `TestWorkbenchMissionInputUploadStoresAndListsWithoutStartingMission`, and `TestZIPInputIsDeliveredToWorkerAndReadBackPerFile` passed against schema 26; the fake Worker receipt confirms extracted text inclusion, original-PDF exclusion, Workbench per-file readback, and `provider_egress=0`. The temporary cluster and database were removed. Full Go tests and command builds also pass. Evidence: `evidence/development/r1-r3-implementation-validation-20260924-slice-12/verification.md`. This foundation does not qualify PDF rendering, OCR, encrypted PDFs, arbitrary page counts, R2 multi-day operation, or real model delivery.
