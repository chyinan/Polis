# R0.15 `tools.call` Contract Draft (PLAN ONLY)

> Status: planning draft (2026-11-07). Field names, enum values, HTTP routes, and storage layout are **non-final** until a separately authorized implementation slice reviews them. **No execution/egress is authorized.**

## 1. Scope

This draft defines the future company-scoped capability `tools.call` request, precondition checks, denial reasons, and receipt shape. It complements:
- `docs/design-plans/R0_15_MCP_TOOL_CALL_QUALIFICATION_GATE.md`
- `docs/implementation/R0.15_TOOL_CALL_GATE_DECISIONS.md`
- `docs/implementation/R0.15_SCHEMA16_MCP_TOOL_CALL_DRAFT.sql` (draft only, not an active migration)

`tools.call` is distinct from read-only `capabilities.tools.list` / `capabilities.tools.describe` (R0.13/R0.14), which remain `callable=false`.

## 2. Request fields (draft)

| Field | Type | Req | Purpose / validation |
| --- | --- | --- | --- |
| `companyId` | string/id | yes | Company scope; must match authenticated/control scope. |
| `employeeId` | string/id | yes | Employee whose approved binding/qualification is evaluated. |
| `taskId` | string/id | cond | Required when call is task-bound; validates task ownership/state/epoch as applicable. |
| `sessionId` / `epoch` | string/int | cond | Required when call runs under a worker/session incarnation; stale epoch denied. |
| `bindingId` | string/id | rec | Pins the exact approved binding; if omitted, resolution rules must be deterministic and deny ambiguity. |
| `handle` | string | yes | `serverId:toolName`; parsed like R0.14 `splitToolHandle` (no whitespace/slashes, valid server ID, no extra colon). |
| `descriptorDigest` | string | yes | Must equal cached frozen descriptor digest for the handle; mismatch is `DESCRIPTOR_DIGEST_MISMATCH`. |
| `arguments` | object | yes | JSON object validated against cached input schema; invalid => `SCHEMA_INVALID`. Bounded size. |
| `idempotencyKey` | string | yes | Caller-provided key scoped to company+employee+handle+operation context (exact scope finalized in implementation). Replays return the original receipt when safe. |
| `policyRevision` | string/id | yes | Pins the evaluated MCPBridge/call policy revision. |
| `authorizationRef` | string/ref | cond | Required for calls whose policy class requires operator authorization; opaque reference to approval receipt/action. |
| `effectClassHint` | enum? | opt | Optional caller hint (`read`, `idempotent`, `effectful`, `unknown`); never trusted over policy. |
| `requestedAt` | time | srv | Server-side timestamp/receipt metadata. |

## 3. Precondition evaluation order (draft)

Evaluation is fail-closed. The implementation may short-circuit, but denial codes should be stable enough for audit/UI mapping.

1. Scope/authn/authz and structural validity (`MALFORMED`, `OUT_OF_SCOPE`, policy auth).
2. Binding approved, enabled, and contains target definition (`BINDING_NOT_APPROVED`, `BINDING_DISABLED`, `BINDING_REVOKED`, `BINDING_TARGET_MISSING`).
3. Definition state not revoked/unverified and handle resolves (`DEFINITION_REVOKED`, `DEFINITION_UNVERIFIED`, `TOOL_NOT_FOUND`).
4. Cached descriptor present/integral and digest matches (`DESCRIPTOR_MISSING`, `DESCRIPTOR_INTEGRITY`, `DESCRIPTOR_DIGEST_MISMATCH`).
5. Arguments validate against cached input schema (`ARGUMENTS_SCHEMA_VIOLATION` for constraint failures, `SCHEMA_INVALID` for malformed descriptor schema, `ARGUMENTS_TOO_LARGE`). If `taskId` is provided, it must exist in the same company (`OUT_OF_SCOPE`/equivalent domain error before receipt path).
6. Call qualification exists and is active for binding+definition+handle+descriptor digest+policy (`CALL_NOT_QUALIFIED`, `CALL_QUALIFICATION_EXPIRED`, `CALL_QUALIFICATION_REVOKED`).
7. Runtime policy allows transport/command/env/egress/effect class (`POLICY_DENIED`, `AUTHORIZATION_REQUIRED`, `EFFECT_CLASS_DENIED`, `TRANSPORT_NOT_QUALIFIED`).
8. Task/session epoch freshness where applicable (`STALE_EPOCH`, `TASK_STATE_DENIED`).

## 4. Denial / outcome codes (draft enum)

Machine-readable `code` values; human `message` must not leak secrets. Grouping is informative.

| Code | Meaning |
| --- | --- |
| `MALFORMED` | Request shape/IDs/handle invalid. |
| `OUT_OF_SCOPE` | Caller or target outside allowed company/employee/binding scope. |
| `BINDING_NOT_APPROVED` | Binding is draft or not approved. |
| `BINDING_DISABLED` | Binding explicitly disabled. |
| `BINDING_REVOKED` | Binding revoked. |
| `BINDING_TARGET_MISSING` | Binding does not include target server definition. |
| `DEFINITION_REVOKED` | MCP definition revoked. |
| `DEFINITION_UNVERIFIED` | Definition not in a state eligible for qualified calls. |
| `TOOL_NOT_FOUND` | Handle/tool absent from cached qualified descriptor set. |
| `DESCRIPTOR_MISSING` | No cached descriptor body for the tool (names-only is insufficient). |
| `DESCRIPTOR_INTEGRITY` | Stored descriptor/probe receipt fails integrity checks. |
| `DESCRIPTOR_DIGEST_MISMATCH` | Request digest differs from cached frozen descriptor digest. |
| `SCHEMA_INVALID` | Cached descriptor input schema is malformed/unusable. |
| `ARGUMENTS_SCHEMA_VIOLATION` | Arguments do not satisfy cached input schema constraints (bounded subset validation). |
| `ARGUMENTS_TOO_LARGE` | Arguments exceed bounded limit. |
| `CALL_NOT_QUALIFIED` | No active call qualification for the exact target/digest/policy context. |
| `CALL_QUALIFICATION_EXPIRED` | Qualification existed but is expired (if expiry is modeled). |
| `CALL_QUALIFICATION_REVOKED` | Qualification revoked/disabled. |
| `AUTHORIZATION_REQUIRED` | Policy requires operator authorization reference; absent/invalid. |
| `POLICY_DENIED` | MCPBridge/runtime policy denies command, env, egress, path, or effect. |
| `EFFECT_CLASS_DENIED` | Declared/evaluated effect class not permitted by policy. |
| `TRANSPORT_NOT_QUALIFIED` | Transport type (e.g., remote/HTTP/OAuth) not qualified for this slice. |
| `STALE_EPOCH` | Session/worker epoch stale. |
| `TASK_STATE_DENIED` | Task state does not permit the call. |
| `IDEMPOTENCY_CONFLICT` | Same idempotency key reused with different request digest/context. |
| `MCP_PROCESS_START_FAILED` | Qualified call reached process start but start failed (post-gate execution failure). |
| `MCP_TRANSPORT_FAILED` | Transport/protocol failure after start. |
| `MCP_TOOL_ERROR` | Tool returned application/protocol error; not a policy denial. |
| `TIMEOUT` | Bounded timeout elapsed; outcome may be unknown/effectful. |
| `CANCELLED` | Call cancelled by authorized control path. |
| `RESULT_TOO_LARGE` | Result exceeded capture bound; bounded truncation/receipt rules apply. |
| `INTERNAL` | Unexpected internal failure; no success fabricated. |

## 6. Compatibility notes

- Read APIs keep `callable=false` unless a later reviewed contract adds derived qualification indicators; such indicators must not authorize calls.
- `toolsCalled` in historical probe receipts remains probe evidence. Call receipts are separate audit objects.
- Any schema 16 persistence must preserve schema 15 read behavior and migration gates.
