# R0.10 Local Capability Probe

> Verified: 2026-10-31

## Delivered

- A library import can name one package, `skills/<package>/SKILL.md`, instead of scanning the whole tree.
- `QualifyStdioMCP` starts the registered stdio command, sends `initialize` and `tools/list`, then stops the process. It does not call tools.
- Migration `00014_r10_mcp_probe.sql` stores the probe receipt. A passed probe sets the definition to `candidate` and leaves connection unprovisioned.
- Group Settings can import that one package and run the connection check.

## Experiment

The operator skill library supplied `brand-guidelines`. The probe parsed it and did not execute a script.

`@modelcontextprotocol/server-memory@2.0.1` was installed outside the repository and probed over stdio. The server identified itself as `memory-server` `2.0.1` on protocol `2024-11-05` and listed nine tools. `toolsCalled` is 0. The child environment was reduced to operating-system path and temp variables. The process was not placed in a network sandbox, so `networkRestricted` is false.
