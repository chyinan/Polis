# R0.11 Skill Reference Read

> Verified: 2026-10-31

## Delivered

After `skills.load`, `context.read` for one skill accessory follows section 44.4.2:

- The reference must be a `references/*.md` name snapshotted when the revision was imported.
- The task, employee, and revision must already have a `skill_loads` row.
- The response returns that frozen text and its content digest.
- `scriptsExecuted` is false. A `scripts/` path is rejected.
- A name that was not snapshotted is out of scope.
- Reading does not insert another load row and does not require the revision to still be approved, so a revoked revision can be re-read from the existing load.
- Reading before a load is denied.

The snapshot lives in the existing skill manifest. Schema stays 15.
