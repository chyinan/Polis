# R0.10 Skill Load

> Verified: 2026-10-31

## Delivered

`skills.load` follows the plan's section 44.4 for a read-only load:

- The caller names one Skill revision, one employee, and one task.
- The task owner must be that employee, and the task must be `ready` or `working`.
- The revision must be `approved`, and the employee's approved capability binding must include it.
- The response returns the stored body, the content digest, and reference filenames captured when the package was imported.
- The same task, employee, and revision return the original load row.
- `scriptsExecuted` is false. `allowed-tools` in the manifest does not become a permission.

Migration `00015_r10_skill_loads.sql` stores the load. Schema gates are 15.
