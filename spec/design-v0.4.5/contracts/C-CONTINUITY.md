### 42.6 C-CONTINUITY：一致接班快照、只读恢复与产物发布 <a id="subsection-42-6"></a>

#### 42.6.1 事实与游标使用同一短快照 <a id="subsection-42-6-1"></a>

接班包、需快照水位的工作台读取，使用同一短 **REPEATABLE READ** 事务取得相关数据库事实、有效版本与公司提交有序 `company_seq`。Read Committed 连续语句可读到不同已提交状态，不能把旧任务内容和较新游标拼成一个包。[P05](../ARCHITECTURE.md#ref-p05)

```sql
-- 示意，不是可直接执行的迁移或完整查询。
BEGIN ISOLATION LEVEL REPEATABLE READ READ ONLY;
-- 在统一公司作用域下读取任务、责任、动作、引用和 company_stream_head。
-- 将结果复制为不可变的事实清单，不在事务中调用模型或读取大型文件。
COMMIT;
```

之后在事务外装配摘要与文件；生成包记录应用生成的 snapshot ID、游标、引用版本、缺失项和内容 hash；snapshot ID 是来源标签，不是事务结束后还能重用的数据库快照句柄。对包构建后的新增事件可靠补齐。激活前重新核对当前授权、关键依赖与恢复代际；一致快照不是永久有效授权。

对文件 GC 使用有期限的 MaterializationLease/保留 pin：取得事实清单前建立有界的防删除保护，取到明确引用后转为精确 pin，再释放宽范围保护。长时间构建需续约；保护已失效或引用缺失时停止发布并重新核对，不假定旧快照文件还存在。具体实现不能在 GC 扫描与新增引用之间无锁竞态，也不能让废弃构建永久占磁盘。

#### 42.6.2 恢复核对阶段没有业务写权限 <a id="subsection-42-6-2"></a>

`restoring / validating` 使用专用 read-only grant：只能读取接班包、冻结产物和必要证据，并发送接班声明。必要的验证工具仅在独立 scratch 使用受控配额运行；不能修改业务工作区、发新协作任务、消费发布许可或扩大授权。

通过核对后，内核原子提交新 employee_epoch 与 Session/Attempt 的激活决定，但先显示 `activation_pending_environment`，不立即派发任务。受信 supervisor 按当前 incarnation/epoch/grant 幂等落实写能力，返回可核对的 capability receipt；内核确认回执仍对应最新授权后才显示 active 和放行工作。

DB 与挂载/OS 授权不是一个原子事务。能力落实失败或回执丢失时保持 pending 并核对，不回滚到已退役 epoch；迟到的旧授权请求由 supervisor 的当前代次/冻结门禁拒绝。写能力落实与撤权也走同一监督门禁，不能让排队的旧 mount/grant 在撤权之后重新生效。旧写者未停止/隔离时不进入此流程；受信 supervisor 不可达则停住，不让 DB 状态冒充 OS 隔离证据。

激活前到来的消息由版本/游标补齐；激活后按正常收件箱继续。`handover.confirm` 只是新模型的声明，程序还要核对可检查的 ID、来源、epoch、责任和产物。 能力清单还包含工作根、SkillRevision 和 MCPBinding/工具描述指纹；恢复只读阶段不执行脚本或写工具，实际环境落实后才可使用。详见第 44.6 节。

#### 42.6.3 产物发布：允许孤立文件，不允许半成品变成证据 <a id="subsection-42-6-3"></a>

```text
创建 staging 记录 → 受限临时写入 → 完成并计算内容指纹
    → 文件 Sync/必要目录持久化 → 同文件系统固定不可变路径
    → 持久化检查成功 → DB 将 ArtifactRevision 标 ready 并写事件
```

文件持久化和 rename 语义要按受支持的 OS/文件系统实测，不能把 rename 当作所有断电场景下绝对可靠。固定路径不对不可信执行者开放覆盖；公司命名空间隔离，不用跨公司去重泄漏内容相等性。

崩溃在 DB 发布前可留下孤立文件，启动核对后回收或认领；DB 引用缺失/损坏文件则标记 `missing/corrupt` 并使受影响验收失效，不能继续绿色通过。不要从“传输成功”或“文件名存在”推出内容完整。

待提交文件可能包含半写入修改。接班只能使用已完成快照或明确标识为待修复的工作区状态，不能包装成完整可运行产物。GC 同时检查活跃任务、未完成责任、接班包和备份 pin。
