## 35. C-UPGRADE：运行时升级、备份、恢复与发布纪律

### 35.1 模型可换，还要允许公司的软件升级 <a id="subsection-35-1"></a>

每次 Attempt 记录运行时 build、数据库 schema、角色/政策版本、事件 schema、上下文构造器、harness 版本、模型 profile 和工具环境指纹。兼容清单说明哪些旧记录可以直接读、哪些需要迁移、哪些必须拒绝执行。

首版不用热升级或两代 worker 混跑。采用维护窗口：冻结新派发 → 排空/停止或隔离在途 → 保存恢复记录 → 一致备份 → 执行受控迁移 → 只读自检 → 核对外部事实 → 检查当前授权 → 分批恢复。

### 35.2 迁移的可信入口 <a id="subsection-35-2"></a>

goose 负责经审阅 SQL 的版本化执行，本项目另保存迁移内容 hash、build 和执行结果；工具本身不证明迁移安全。[N08](../ARCHITECTURE.md#ref-n08) 迁移使用独立角色，业务进程不持有 DDL 权限。禁止业务启动时“看起来缺列就自动补”；禁止改写已发布迁移和默认自动 down。

每次变更在真实 PG 上测新建库、从前一支持 schema 升级、失败中断以及重新启动。回退程序版本只有 schema 兼容才允许；否则停在维护态或从已验证备份恢复，不能 blindly downgrade。

PG major 升级与应用 schema 迁移是两件事；官方 major 升级需要 dump/reload 或 pg_upgrade 等路径，补丁升级也需按发布说明验证。[N02](../ARCHITECTURE.md#ref-n02) 发布清单锁定镜像摘要，不让自动拉取最新镜像替换正在跑的主库。

### 35.3 首版一致备份流程 <a id="subsection-35-3"></a>

一套公司备份不是只有数据库。首版为简化正确性，暂停写调度并等待相关工作和后台收集落盘，取得备份锁与产物保留 pin；生成 PG 一致备份、必要角色/扩展元信息、已引用不可变产物清单、兼容清单及校验和。数据库、文件与清单全部存在并校验后才标 `backup_ready`。

pg_dump 能在数据库内部形成一致备份，但不自动包含文件产物；PITR/物理备份也需处理应用外部存储。[N09](../ARCHITECTURE.md#ref-n09) 在线增量备份和远程对象存储后续再优化，不把普通目录复制当解决方案。

备份不含明文密钥；加密备份的恢复密钥由人/受控密钥管理保管，不与唯一备份同损坏域。备份应有宿主以外的副本才覆盖宿主磁盘丢失；本地第二目录只防部分逻辑误删，不能宣称灾备。

### 35.4 恢复默认不接通真实世界 <a id="subsection-35-4"></a>

导入先进入 `restore_inspection`：网络副作用禁用，重绑定 SecretRef，恢复当前删除/撤权记录，核对 Action 回执、未结算成本、租约、版本和待办。只有全部所需核对完成并获恢复授权才派发。

数据库恢复到过去，不代表外部平台也回到过去。恢复镜像中的未发送记录可能事实上已发送；未知情况必须查询真实结果或人工决定，不重放历史 outbox 执行一次发布/退款。

### 35.5 恢复目标必须量化但不能虚构 <a id="subsection-35-5"></a>

RPO 分别记录关键事务、原始模型文本、公司备份的容许损失窗口；RTO 区分恢复只读总览与恢复安全派发所需时间。数值由 G0/G1 实验填实。没有完整备份/restore 演练时只能宣称会话/进程恢复，不宣称整机故障无损恢复。

### 35.6 发布门禁与运行时自修改 <a id="subsection-35-6"></a>

员工可以在隔离仓库里帮助开发本项目下一版；不能对当前正在约束自己的二进制、政策、测试器、migration 或主数据库进行自批准替换。发布必须经外部可信管理流程、独立验收、版本清单、许可证/依赖清单和回退计划。

安全问题报告通道、支持矩阵、CHANGELOG 与已知限制随首个公共 release 提供。项目自身许可证在公开发布前明确，不因参考项目开源就省略来源与依赖义务；本版不作法律兼容结论。

### 35.7 工作环境配置与文件进入备份 <a id="subsection-35-7"></a>

备份清单覆盖已批准 SkillRevision、绑定/描述版本、引用文件与必要 ToolInvocation；不备份可直接复用的明文凭据或远端 bearer handle。导入暂停，重建 endpoint/工作根映射并核对现行能力撤销和依赖版本；丢失的 Skill 包不得从同名“最新版”自动替代。服务实现版本可查但无法冻结远端时明确限制。
