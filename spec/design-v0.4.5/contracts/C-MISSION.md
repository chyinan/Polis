### 42.2 C-MISSION：唯一启动、使命占用与收尾 <a id="subsection-42-2"></a>

#### 42.2.1 从启动命令到第一份工作 <a id="subsection-42-2-1"></a>

保存公司和Mission草案不执行模型。`StartMission`核对管理身份、当前版本、基础Agent读/规划环境、使命授权、预算与资源；项目依赖尚未ready不阻止获准的bootstrap/环境准备。按任务类型准入，见12.1/46.6。通过检查后在一个短事务内：

1. 锁定公司使命占用记录并核对当前 MissionRevision；已由同一使命占用则返回对应启动状态，不重建组织。
2. 建立持久 `MissionActivation`，保存稳定 activation_id 与命令回执。首版不重开已终结使命；继续同一未终结使命使用 resume，另一个长期目标新建 Mission。
3. 创建唯一的 `bootstrap_plan` 任务，约束为 `(mission_id, activation_id, bootstrap_kind)` 唯一；重复键或不同 request_id 的重复启动仍不得创建第二份。
4. 负责人来自人确认的现有规划岗位。输出合同来自受版本管理的 BootstrapTemplate，不依赖尚不存在的项目计划。
5. 写入 WorkSignal/outbox、公司流事件和运行阶段 `phase=bootstrap` 后提交；只有提交成功才按现有规则进行付费执行准入。

BootstrapTemplate 至少要求输出：近期里程碑、可执行任务、负责人、依赖、可检查验收安排、关键假设与待确认歧义。任务本身有时间/费用上限；无合格规划员工时返回有理由的阻塞，不自动聘用替身。初始规划可以创建后续验证工作，但不能自行改写人批准的成功标准或授予新权限。

计划接受只证明结构和授权有效，不证明路线一定正确；领域质量检查与独立验收仍按第 13、30 章执行。只有确实阻止推进的重要歧义才形成 HumanIntervention；不要求人提前手写全部子任务。

```text
创建组织（无推理）→ 明确启动使命
                    → 事务性唯一 bootstrap 工作
                    → 唤醒固定规划员 → PlanProposal
                    → 结构/授权/资源检查 → 现有员工并行工作
```

#### 42.2.2 “一个活跃使命”不是只检查 active 枚举 <a id="subsection-42-2-2"></a>

新增 `CompanyMissionSlot`，记录尚未释放的使命占用。`active`、`waiting`、`paused`、`evaluating`、`closing` 等未终结生命周期都占槽；额度等待和人工暂停不能被当作可启动第二使命的理由。`phase=bootstrap` 是执行阶段，不增加另一套公司状态真相。

首版同公司一次只有一个未释放使命。计划修改是版本修订，不是重建 activation。重复 start 对已启动使命只返回现状或明确冲突；对已终结使命拒绝重新启动，防止旧消息和旧授权被复活。

#### 42.2.3 收尾分离业务关闭与历史账务核对 <a id="subsection-42-2-3"></a>

在成功候选、明确失败、到期或取消后进入 `closing`，记录拟议 `terminal_reason`。关闭流程必须先阻止新业务任务、周期实例及旧工作线唤醒，再处理在途事项：

| 项目 | 收尾要求 |
|---|---|
| 周期职责与待执行任务 | 停止产生新 occurrence；已有实例明确取消、过期或保留，不静默删除 |
| 员工承诺 | 逐项以已履行、明确取消或有授权的移交闭合；“取消”不能记为“验收通过” |
| 写工作区和外部操作 | 排空、停止或有效隔离；不能用关闭状态掩盖仍能写入的旧执行 |
| 产物和证据 | 固定版本、保留必要 pin，发布带缺失项的报告；未知项不能填成通过 |
| 费用与迟到回执 | 允许程序继续对旧 Action/Attempt 结算，归属旧使命，不唤醒旧业务 |

业务执行权已收回、受影响资源已安全交接、未决责任有明确处理后，才设置终态并释放使命槽。未结算费用本身不必永久占槽，但继续占用父级预算的 unknown liability；不能释放同一个仍可能被旧动作修改的外部资源。不能确认隔离的动作阻止相关资源释放并产生接管事项。

`MissionSucceeded` 只能在既定验收满足时产生；不能把 cancelled、ended_not_met 或无法核对的效果改名为 succeeded。终态历史不可被迟到消息直接重开；所有后续任务必须属于新的有效使命。
